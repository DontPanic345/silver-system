Happens when a placeholder post is used to test the blog's format instead of a real bug.

1. Copy this file to `_posts/YYYY-MM-DD-short-slug.md`.
2. Set `title` to the exact error/symptom text (what someone would paste into a search bar).
3. Set `date` to today.
4. Replace this context line with a one-line description of when the error happens.
5. Replace these steps with the actual numbered fix.
6. Delete this example post once real posts exist.

### Why

Front matter carries the searchable error text, the body stays terse (context + numbered
steps only) so it reads fast under a rushed search, and an optional "why" section like this
one is added only when the root cause isn't obvious from the fix itself.
