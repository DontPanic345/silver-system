# Dictation dumps

Raw, unedited source material — voice-dictated notes and reflections, kept
verbatim (typos and all) for provenance. **Nobody needs to read these to work
in this repo.** Whatever's actually useful in them has already been distilled
into `NORTH_STARS.md` (aspirational statements) and `PRINCIPLES.md`
(aphorisms); `JOURNAL.md` cites them where they explain a real pivot. Read
one of these files directly only if you have a specific reason to check the
distillation against the source — e.g. the open task below.

- **`agentic-development.md`** (dictated 2026-09-05) — mostly a full
  specification of the tranche/milestone/round/phase Red-Green-Refactor
  cycle that ran as `night-shift` and has since been shelved (see
  `night-shift/CLOSEOUT.md`). Also contains, undistinguished from that
  process detail: the "believable small world" statement, all four
  `PRINCIPLES.md` entries, the physics → chemistry → biology → glass-pane
  domain ordering (`NORTH_STARS.md` #3), and the doubt about a standing
  determinism requirement that later became "architecture-contingent."
- **`response-to-tdd-cycle.md`** (2026-09-03) — reflection questions on the
  stable-fluids TDD cycle's close-out, written two days before the above.
  Several of its questions turn directly into decisions in
  `agentic-development.md` (e.g. "maybe Red writes skeleton code too" here
  becomes a stated decision there).
