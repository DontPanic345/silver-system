# silver-system

An experimental small-world simulation project — emergent physical behaviour
from simple interacting rules, in the spirit of Oxygen Not Included and Noita.
Each experiment here has run under its own approach; none has been kept once it
stopped earning its keep. See [`NORTH_STARS.md`](NORTH_STARS.md) for every prior
experiment's stated goal and why it went stale — read it before writing a new
one, so it isn't a repeat.

## What's here

- `src/`, `www/`, `tests/`, `scripts/` — Rust substrate from the `night-shift`
  experiment (grid/material types, a scenario harness, a minimal wasm renderer,
  a native fallback). Kept as starting material; not under active process. See
  `README.md` for how to build and test it.
- `terrarium/`, `stable-fluids/`, `night-shift/` — shelved experiments, kept for
  reference. Do not extend them.
